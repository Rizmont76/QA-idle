# QA Idle

QA Idle — браузерна idle-гра про кар’єру тестувальника: від першого багу до Director.

Знаходь баги, здавай звіти, наймай команду й автоматизуй дохід. Шість рангів,
чотири типи виробників, 15 покращень, контракти та 10 досягнень. На Director можна
почати нову кар’єру з постійним досвідом, стартовими грошима й автоматичними звітами.

Прогрес зберігається локально. Команда працює офлайн до 8 годин (16 із покращенням).
Резервні копії можна експортувати та імпортувати в налаштуваннях; старі сейви MVP
переносяться автоматично в тому самому браузері та на тій самій адресі.

## Як грати

1. Знайди кілька багів і здай звіт.
2. За $25 найми першого QA-помічника — він шукатиме баги сам.
3. Виконай видимі умови підвищення до Middle та придбай автозвіти за $80.
4. Розвивай команду, виконуй контракти й рухайся до Director.
5. Обміняй успішну кар’єру на постійний досвід і пройди наступну швидше.

## Project Layout

- `src/` - game source code
- `docs/` - production design and architecture documentation

## Local Development

```bash
pnpm install
pnpm run dev
```

## Перевірка і збірка

```bash
pnpm run check
pnpm run build:portable
```

`dist/` — готовий сайт для статичного хостингу. `dist/qa-idle.html` — автономний
файл гри: відкрий його сучасним браузером без сервера та інтернету. Збереження
прив’язане до браузера й адреси/файла; перед перенесенням зроби експорт у налаштуваннях.

Активна специфікація: [Career Idle Release](docs/16-Career_Idle_Release.md).
Попередні модулі MVP та їхні тести збережено як історичну базу для міграції.
